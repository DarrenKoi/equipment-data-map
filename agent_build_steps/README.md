# agent_build_steps — 스크립트를 agent로 키우는 실습 과정

이 폴더는 **이 저장소를 유지보수하는 사람(당신)** 을 위한 학습 자료다.
office 에이전트의 계약은 `equipment-data-parser/index.md` 이고, 이 폴더는
거기에 들어가지 않는다. 읽는 사람이 한국어를 쓰므로 `docs/` 와 같은 규칙으로
한국어로 쓴다.

목표: `spike.py` 한 장짜리 스크립트를, **장비 한 대가 아니라 아무 파일 저장소에나
붙일 수 있는 agent** 로 키우는 과정을 단계별로 직접 해보는 것.

## 한 문장 방법론

> **모델이 바뀌어도 참이어야 하는 것은 전부 harness 에 넣는다. 나머지만 프롬프트다.**

코드를 한 줄 쓸 때마다 던지는 질문은 이거 하나다 — "이 판단이 틀리면 누가
책임지나?" 틀리면 안 되는 것(경계, 예산, 재개 지점, 완료 판정)은 코드.
틀려도 되는 것(이 디렉터리가 뭐 하는 곳인지 추측)은 모델.

## agent = coding + harness 를 셋으로 쪼개면

harness 가 갖춰야 할 성질은 딱 세 가지다. 이 셋이 없으면 "agent" 는 그냥
감독 없는 모델이다.

| 성질 | 뜻 | `spike.py` 의 원형 |
|---|---|---|
| **경계 (bounded)** | 할 수 없는 일은 시도조차 wire 에 못 나간다 | `inside()`, `denied()`, `budget` |
| **관측 (observable)** | 무슨 일이 있었는지 기계가 읽을 수 있다 | 마지막 줄 JSON `stats` |
| **판정 (verifiable)** | 끝났는지 아닌지를 모델이 아니라 코드가 말한다 | 세 boolean `index_exists` / `md_per_dir` / `evidence_tables` |

`spike.py` 는 이미 셋 다 **씨앗 형태로** 갖고 있다. 이 과정은 새 설계를
들여오는 게 아니라 저 셋을 각각 자라게 하는 것이다. 단계마다 "어느 성질을
키우는가" 를 표로 붙여 뒀다.

## 프로세스 플로우

```
           [지금] spike.py — 사람이 돌리는 스크립트
                    |
  1. 경계를 테스트로 못 박기 ........... 경계
                    |
  2. 상태를 파일로 내보내고 재개 ....... 관측
                    |
  3. 동사로 쪼개기 (walk/sample/...) ... 경계 + 관측
                    |
  4. LLM 을 계약 뒤에 세우기 ........... 판정
                    |
  5. 루프를 닫는다 = agent ............. 판정
                    |
  6. 사이트 차이를 데이터로 빼기 ....... 보편화
                    |
           [끝] 아무 파일 저장소에나 붙는 agent
```

각 단계는 **앞 단계가 통과해야** 시작한다. 순서를 바꾸면 5단계에서
"모델이 왜 저랬는지" 를 설명할 수 없게 된다 — 그게 이 순서의 전부다.

## 각 단계를 하는 법

단계 파일마다 같은 네 칸이 있다.

- **왜** — 이 단계가 없으면 뭐가 깨지는지. 읽고 납득 안 되면 건너뛰어라.
- **개념** — 이 단계에서 배우는 것 (다른 프로젝트에도 쓰이는 부분)
- **실습** — 이 저장소에서 실제로 칠 명령과 쓸 코드
- **통과 기준** — 코드가 판정하는 한 줄. 사람 감이 아니다.

통과했으면 `progress.md` 가 아니라 이 폴더의 `log.md` 에 한 줄 남긴다
(letter 진행 기록과 섞이면 안 된다):

```
- step 1 done 2026-09-13 | 경계 테스트 4개, roots 밖 경로가 wire 에 안 나감
```

## 하지 않을 것

- 승인 게이트, 5단계 rollout, 4-tool skill suite — 2026-09-11 에 범위 밖으로
  결정됐다 (issue #1). 이 과정은 그걸 되살리지 않는다.
- agent 프레임워크 도입. 5단계까지 오면 agent 는 "CLI + SKILL.md 한 장" 이다.
  그 이상이 필요해지면 그때 필요해진 이유를 적고 도입한다.
